Engine‑facing scripts

Some scripts are read directly by the engine rather than by Squirrel: major events, spawn scripts for emergent factions. They cannot be replaced by Squirrel, but Squirrel can drive them through event counters and hidden resources. These pages explain how, and where the seams are.

How to use these pages offline

  1. Save all files as .html, and keep style.css and navbar.js alongside them.
  2. Open index.html in a browser. The links work as long as every file sits in the same folder.
  3. To convert a page to a Word document, open it in a browser, then use File → Save As → Word Document (.docx), or open the .html directly in Word.
  4. To share the set with other modders, zip the whole folder and hand it over. Nothing here depends on a live server.
A note on the API. The REX Squirrel API is still evolving. Wherever this guide says "check the API docs", it means the generated api.d.nut file that ships with REX — that file is the single authoritative source for event names, payload fields, and object properties. If a page here disagrees with api.d.nut, trust api.d.nut, and please update the page.
